SUBBAB 6 – KONVOLUSI

Konvolusi

Pustaka Pillow umumnya digunakan untuk membuka, menyimpan, dan melakukan pemrosesan citra dasar. Namun pada Pillow pengaturan proses konvolusi dan cara piksel di bagian tepi citra diproses masih terbatas. Oleh karena itu, untuk melakukan konvolusi dengan pengaturan kernel dan penanganan tepi citra yang lebih lengkap digunakan pustaka SciPy.

import numpy as np
from scipy.signal import convolve2d

SciPy menyediakan fungsi convolve2d yang digunakan untuk melakukan konvolusi dua dimensi pada data berbentuk matriks, seperti citra digital yang telah diubah menjadi array. Melalui fungsi ini pengguna dapat menentukan kernel yang digunakan serta cara penanganan piksel di bagian tepi citra sesuai kebutuhan pemrosesan.

import numpy as np
from PIL import Image
from scipy.signal import convolve2d

img = Image.open("gambar.png").convert("L")
image = np.array(img, dtype=np.float32)

kernel = np.array([
  [0, -1, 0],
  [-1, 4, -1],
  [0, -1, 0]
], dtype=np.float32)

hasil = convolve2d(
  image,
  kernel,
  mode="same",
  boundary="symm"
)

Pada kode di atas, citra terlebih dahulu dikonversi menjadi grayscale, kemudian diubah ke dalam bentuk array agar dapat diproses menggunakan perhitungan numerik. Kernel yang digunakan pada contoh di atas adalah kernel Laplacian 3×3 yang berfungsi untuk mendeteksi tepi (edge detection) pada citra. Berbeda dengan penghalusan (smoothing), kernel ini akan menonjolkan garis-garis batas objek pada gambar.

Parameter mode="same" digunakan agar ukuran citra hasil konvolusi tetap sama dengan citra asli. Sementara itu, parameter boundary="symm" digunakan untuk memberikan padding pada bagian tepi citra dengan cara mencerminkan (reflect) nilai piksel di sekitarnya. Selain symm, SciPy juga menyediakan padding lain seperti fill yaitu constant padding yang secara default mengisi tepi citra dengan nilai nol (zero padding), namun nilainya dapat diatur menggunakan parameter fillvalue, misalnya fillvalue=128. SciPy juga menyediakan wrap yaitu padding yang mengisi tepi citra menggunakan piksel dari sisi berlawanan sehingga citra diperlakukan seolah-olah melingkar.

Hasil konvolusi kadang menghasilkan nilai piksel yang terlalu kecil (kurang dari 0) atau terlalu besar (lebih dari 255). Padahal citra grayscale hanya dapat menampilkan nilai piksel dalam rentang 0 sampai 255. Oleh karena itu nilai piksel hasil konvolusi perlu disesuaikan kembali agar sesuai dengan rentang nilai citra digital melalui proses normalisasi.

min_val = hasil.min()
max_val = hasil.max()

hasil_norm = (hasil - min_val) / (max_val - min_val) * 255

hasil_conv = hasil_norm.astype(np.uint8)
Image.fromarray(hasil_conv)

Pada kode di atas, nilai piksel terkecil dan terbesar dari hasil konvolusi dicari terlebih dahulu. Kemudian, rumus normalisasi diterapkan secara langsung agar semua piksel didistribusikan ulang ke dalam rentang 0 hingga 255. Setelah itu, hasil perhitungannya diubah ke tipe data uint8 sehingga dapat digunakan sebagai citra grayscale standar dan diproses atau disimpan kembali.
